# A fork of unison-for-termux rewritten as a fish script
# to run in termux
```fish
git clone https://github.com/AK20481/unison_termux.fish
cd unison_termux.fish
chmod +x unison_termux.fish
./unison_termux.fish
```
# or alternatively
# curl -sSL https://raw.githubusercontent.com/AK20481/unison_termux.fish/refs/heads/main/unison_termux.fish | fish
